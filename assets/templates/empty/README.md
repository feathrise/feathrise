# 空工程

本工程从空地图目录开始，不附带角色模型、装备、技能、任务、剧情或示例地图。
在编辑器创建自己的场景和资源。工程3D通过“预览”进入运行、“返回”恢复编辑；编辑器3D通过“启动”独立运行已保存的工程。在工程目录执行cargo run同样读取已保存内容。

当前空模板加载场景并默认提供 Bevy 0.19.1 原生自由相机，不附带角色、技能或物品模块。进入预览或独立运行后，W/A/S/D 前后左右移动，Q/E 降低／升高，按住右键并移动鼠标环视，M 切换鼠标锁定，左 Shift 加速，滚轮调整移动速度。自由相机可穿过地形与对象，方便检查场景；它不包含角色碰撞、重力或跳跃。

工程清单的 `game_view` 保留斜向与俯视两种 3D 初始观察角度，进入后都可自由移动。`src/controller.rs` 只给场景创建的唯一主相机附加原生 `FreeCameraPlugin` / `FreeCamera`，资源流送观察点随运行相机移动。工程3D的编辑态暂停控制器，返回编辑或窗口失焦会释放鼠标并清除移动惯性，重新进入时恢复运行相机姿态；编辑相机不受它控制。旧工程不会被打开、保存或启动操作自动改写模板源码。
新建时由编辑器源码根或 EXE 旁的 `sdk-source.toml` 统一选择 SDK 来源，缺少外置配置时采用程序内嵌的默认配方。默认使用 crates.io SDK `=0.1.0`，八项第三方补丁来自公开补丁仓的固定完整提交，不依赖开发机 SDK 或补丁源码目录。只有显式选择 `kind = "path"` 才生成本地路径依赖；选择 `kind = "git"` 时使用明确的 SDK 与补丁提交。工程的实际来源固定在自己的 `Cargo.toml` / `Cargo.lock`，编辑器后续修改新建配置不会修改这个工程；升级已有工程须作者显式调整其依赖并重新验收。

新建会复制编辑器的锁文件作为版本种子，再用 `cargo fetch` 补齐当前工程的依赖身份，保留仍兼容的锁定版本；不执行全量升级或重新生成锁。默认 registry 与显式 Git 来源允许首次联网获取；显式本地来源使用 `--offline`。依赖缺失或获取失败时保留明确诊断，不发布半成品工程。
