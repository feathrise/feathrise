# 空工程

本工程从空场景目录开始，不附带角色模型、装备、技能、任务、剧情或示例场景。
在编辑器创建自己的场景和资源。工程3D通过“预览”进入运行、“返回”恢复编辑；编辑器3D通过“启动”独立运行已保存的工程。在工程目录执行cargo run同样读取已保存内容。

空模板加载场景并提供所选 Bevy 版本的原生自由相机。进入预览或独立运行后，W/A/S/D 前后左右移动，Q/E 降低／升高，按住右键并移动鼠标环视，M 切换鼠标锁定，左 Shift 加速，滚轮调整移动速度。自由相机可穿过地形与对象，方便检查场景。

工程清单的 `game_view` 保留斜向与俯视两种 3D 初始观察角度，进入后都可自由移动。`src/controller.rs` 只给场景创建的唯一主相机附加原生 `FreeCameraPlugin` / `FreeCamera`，资源流送观察点随运行相机移动。工程3D的编辑态暂停控制器，返回编辑或窗口失焦会释放鼠标并清除移动惯性，重新进入时恢复运行相机姿态；编辑相机不受它控制。旧工程不会被打开、保存或启动操作自动改写模板源码。
新建时由编辑器源码根或 EXE 旁的 `sdk-source.toml` 选择 SDK 来源，统一使用 Feathrise SDK 0.3.x、Bevy 0.20.1 及配套补丁。源码工作区使用同级 SDK 和补丁。单文件安装缺少外置配置时使用内嵌的 SDK 0.3.0 Registry 配方。工程的实际来源固定在自己的 `Cargo.toml` 和 `Cargo.lock`。

新建会复制 Bevy 0.20.1 的锁文件种子，再用 `cargo fetch` 补齐当前工程的依赖身份，保留仍兼容的锁定版本。Registry 与 Git 来源允许首次联网获取，本地来源使用 `--offline`。
