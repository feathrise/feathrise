# 剧情演出与视频导出

在「文件 → 新建 → 剧情演出」创建演出，双击工程中的 `.cinematic.json` 可以继续编辑。演出 ID 存在资产内部，文件名和目录可以按项目需要调整。

镜头轨记录当前视口机位和视野角。相邻机位可以直接切换，也可平滑过渡。角色、物件轨可以记录变换并编排已有具名动画。对白轨既可放一句字幕，也可引用工程的 Yarn 节点。把游标移到任意时间可以检查那一刻的姿态，停止预览可以交回原机位。在「交互」的工程触发规则中添加 `cinematic.play` 请求，目标填写演出 ID，地点、道具、战斗或变量规则都可使用同一资产。

## 导出宣传片

1. 保存演出和场景，在演出页点击「导出视频…」。
2. 确认 MP4 输出路径、画面尺寸和帧率。默认 1920×1080、30 帧/秒，宽和高取正偶数。场景 ID 默认取已打开的场景，留空使用工程开局。
3. 需要调整等待对白停留、指定子场景实例或加配乐时，打开「高级设置」。配乐从影片开头播放，过长时剪至片尾，过短时补静音。本版声音来自这条配乐轨。
4. 点击「导出 MP4」。遇到未指定的 Yarn 分支时，在面板点选要拍摄的对白即可继续。如果要提前指定分支，可以在「高级设置」填 `{"拜师:1":"接受"}`，其中「拜师」是对白轨的台词 ID，`1` 是该对白中第一个出现的选择组。选项值优先匹配稳定行 ID，也支持唯一的显示文字。
5. 已有同名影片时，可另选文件名或打开「允许覆盖」。导出中可点「取消导出」或按 Esc。取消、GPU 回读或编码失败都会保留已有影片。

工程运行程序需要支持影片协议 v1。编辑器在独立工程进程中使用真实主相机和同一演出采样器，输出画面只含场景和演出字幕。每一帧收到 GPU 回读后才推进片中时间，机器的实时帧率不会改变片长。

本地联调时，在新建工程前选择包含该协议的 SDK 源码。已有工程需将 Cargo 依赖更新到包含该协议的 SDK 并重新构建。[配置 SDK 来源](./使用说明.md#sdk-来源)

编码使用含 `libx264` 的 FFmpeg。带编码器的 Windows 单文件发行版在第一次导出时自动准备工具，之后在同一用户的本地缓存复用。要手动指定版本，可在「高级设置」填写可执行文件的完整路径，或设置 `FEATHRISE_FFMPEG`。源码版未指定编码器时，Windows 会先查找开发机的 `D:/SDK/ffmpeg/bin/ffmpeg.exe`，再从 PATH 查找。在工程中实时播放演出无须调用编码器。

摄影期间系统临时目录存放当前影片的逐帧 PNG。导出完成或取消后，编辑器清理本次工作目录。
